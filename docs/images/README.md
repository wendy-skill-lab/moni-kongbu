- `usage-floorplan.png`：案例实际制作并确认过的俯视方位图。图中文字中的人物与关系是虚构角色。保留原图，以便观察机位、人物位置和线索如何统一。
- `usage-master-options.jpg`：案例实际生成的六张监控场景母版候选。它不是六张真实监控照片；有些候选画上了错误时间戳或方向不符，教程保留它们用于说明如何筛选。
- `usage-master-frame.jpg`：案例选出的红外后期候选图。画面由 AI 生成并经过后期，不是实拍或实际护理记录。案例阅读时仍在母版确认阶段，不能据此声称完整影片已完成。
- `usage-asset-board-demo.png`：本次为使用教程制作的资产板教学排版，嵌入前述原创案例图并使用灰色占位。不是原任务的资产板截图，分段是教学分组，状态不代表原任务完成情况；没有为它生成额外剧情素材。
