# 第四步：封面、发布文案和交付

## 封面（3:4，1080×1440）

底图用片中那一帧最能截图的标志画面，跟着这一期的主表达走：《宝宝一直在笑》是夜视里脸朝墙站在墙角的爸爸，《已就寝》是熄灯后坐得笔直的全班加满屏绿框；主表达是痕迹、声音、文字时，就用那张热成像、那条“说话人3：还有我。”的转写、那串门锁记录，配上系统字段。不用放大的人脸，让观众从阴影里、从系统字段里感觉到不对劲。

**标题块整体放在上方**：「模拟恐怖」小标签、大字片名、一行副标题，全部排在画面上部（OSD 时间戳下面）。下半部分不放任何标题字，留给画面，避开抖音主页网格的播放量位置和信息流底部的文字栏。副标题用一句钩子或一条系统推送，不剧透结局，比如“班主任：今晚全班已就寝”。

出主封面和备选两版。模板是 `templates/cover/cover.html`（`?v=A` 和 `?v=B` 两版）加 `shot.js`（Playwright 截图），导出 `<片名>_封面_3x4.jpg` 和 `<片名>_封面_3x4_备选.jpg`。封面上的检测框、分数要和成片一致（分数在 0.9x 浮动，不是一排 1.00）。封面过于直白时换成更克制的画面。

## 发布文案（固定格式，和成片、封面一起交付）

存为 `<片名>_发布文案.md`，并在消息里贴出全文。

```
## 标题（任选一个，推荐第 1 个）
1. 「模拟恐怖」<片名>｜<题材，如“家长看班监控”“婴儿看护器笑声提醒”>
2. 「模拟恐怖」<片名>｜<钩子一>
3. 「模拟恐怖」<片名>｜<钩子二>

## 封面字
<和封面副标题一致的一句话>

## 正文
> <第一人称短句 4–6 行：轻松起点（时间 + 人物 + 日常）→ 第一处不对 → 升级 → 停在一个让人发毛的事实上。不剧透结局。>
>
> 建议戴耳机，看到最后。
>
> 全程由Manus制作。
> 虚构演绎，人物、<学校、小区、品牌等>与聊天记录均为虚构，含惊吓音效。
>
> #模拟恐怖 #伪人 #细思极恐 #Manus #AI短片

## 置顶评论（任选一条）
- <指向一个可以暂停回看的细节，写准确时间点>
- <点出一个细思极恐的逻辑问题>
```

固定规则：

| 规则 | 说明 |
| --- | --- |
| 标题前缀 | 永远是「模拟恐怖」，题材词放在“｜”后面 |
| 署名 | 固定写“全程由Manus制作。” |
| 话题标签 | 永远只有这 5 个：`#模拟恐怖 #伪人 #细思极恐 #Manus #AI短片`（平台上限 5 个，不增不减） |
| 不写“无突脸” | “到底有没有突脸”是评论区的头号互动话题 |
| 时间点 | 按含 3.5 秒观看提示的发布版计算：从 `film_data.json` 读事件时刻再加 3.5 |
| 虚构声明 | 必须有，不伪造新闻、警方、官方通知 |

《已就寝》的正文示例：

> 21:14，看班监控里，儿子又趴在最后一排睡觉。
> 我让班主任把他拽起来，不行就让他去后面站着。
> 22:12，学校公众号提醒我：他没就寝。
> 班主任说，宿管看着他躺下了。
> 可监控里，熄了灯的教室，他还在那个墙角站着。

置顶评论示例：“1:26 陈默发来‘妈，我洗漱完上床了，别管了’。可 1:44 声音一打开，他的手机明明在教室里、在他裤兜里响，人一动没动。那条消息是谁发的？”

## 交付清单

成片（含 3.5 秒观看提示）、无提示版、3:4 主封面和备选、发布文案、视觉呈现脚本、README（含修改记录）。最终消息里给每个文件一个链接，写明时长、规格和这一版改了什么。如果有声音试听，单独列出试听文件，请用户挑。

## 分享物料（用户要求时再做）

**图文卡片**（比如拆解某一期的工作流和提示词）：从成片按时间点抽关键帧，裁出实拍画面区域；用 HTML 写 1080×1440 的多张卡片，Playwright 逐张截图，检查文字有没有溢出；先拼总览图检查字号，再打包成 zip。

**小红书笔记**：标题不超过 20 字，正文按“结果 → 方法 → 提示词 → 互动”写，配图用卡片。

**头像与主页背景**：头像应符合原创人物或账号定位；背景按平台规格裁切，先检查主页显示效果。
