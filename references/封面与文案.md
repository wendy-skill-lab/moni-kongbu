# 第七步：封面、发布文案和交付

## 封面（3:4，1080×1440）

底图用第三步确认、第五步资产板与第六步成片一致的标志画面。公开虚构范例《宝宝一直在笑》用了夜视中的异常熟人，《已就寝》用了全班坐直加检测框；新片学习机制，不复制“站墙角”画面。痕迹、声音或文字主导时，用对应记录和字段。不要放大鬼脸，让观众从阴影、行为或数字感觉不对劲。

**标题块整体放在上方**：「模拟恐怖」小标签、大字片名、一行副标题，全部排在画面上部（OSD 时间戳下面）。下半部分不放任何标题字，留给画面，避开抖音主页网格的播放量位置和信息流底部的文字栏。副标题用一句钩子或一条系统推送，不剧透结局，比如“班主任：今晚全班已就寝”。

出主封面和备选两版。模板是 `templates/cover/cover.html`（`?v=A` 和 `?v=B` 两版）加 `shot.js`（Playwright 截图），导出 `<片名>_封面_3x4.jpg` 和 `<片名>_封面_3x4_备选.jpg`。封面上的检测框、分数要和成片一致（分数在 0.9x 浮动，不是一排 1.00）。封面过于直白时换成更克制的画面。

## 发布文案（固定格式，和成片、封面一起交付）

存为 `<片名>_发布文案.md`，并在消息里贴出全文。

```
## 标题（任选一个，推荐第 1 个）
1. 「模拟恐怖」<片名>｜<题材，如“家长看班监控”“婴儿看护器笑声提醒”>
2. 「模拟恐怖」<片名>｜<钩子一>
3. 「模拟恐怖」<片名>｜<钩子二>

## 封面字
<和封面副标题一致的一句话>

## 正文
> <第一人称短句 4–6 行：轻松起点（时间 + 人物 + 日常）→ 第一处不对 → 升级 → 停在一个让人发毛的事实上。不剧透结局。>
>
> 建议戴耳机，看到最后。
>
> <准确制作来源：确为全程使用 Manus 时写“全程由Manus制作。”；否则写“由 Manus 辅助制作，部分素材由作者提供。”等真实说明。>
> 虚构演绎，人物、<学校、小区等虚构名称>、聊天及设备记录均为剧情设定，不代表真实事件。含恐怖、惊悚元素。
> <含 AI 生成素材时，按平台要求保留 AI 内容标识；出现真实产品名称时不宣称品牌授权或认可。>
>
> #模拟恐怖 #伪人 #细思极恐 #Manus #AI短片

## 置顶评论（任选一条）
- <指向一个可以暂停回看的细节，写准确时间点>
- <点出一个细思极恐的逻辑问题>
```

固定规则：

| 规则 | 说明 |
| --- | --- |
| 标题前缀 | 永远是「模拟恐怖」，题材词放在“｜”后面 |
| 署名 | 如实说明制作来源；只有确实全程使用 Manus 时才写“全程由Manus制作。” |
| 话题标签 | 本流程固定这 5 个：`#模拟恐怖 #伪人 #细思极恐 #Manus #AI短片`，发布时仍核对平台当前规则，不以标签替代 AI 标识 |
| 不写“无突脸” | 文案不提前解释悬念；观看提示仍明确惊悚与谨慎观看 |
| 时间点 | 按含 3.5 秒观看提示的发布版计算：从 `film_data.json` 读事件时刻再加 3.5 |
| 虚构声明 | 必须有；封面和成片也显著标注，无观看提示副本同样不能冒充真实录像 |

发布前读 `资源说明.md`：不要使用未经授权的真人头像、声音、私人聊天或机构标识；不要伪造新闻、警方和官方通知。真实产品名称与图标不因为剧情虚构而变成“虚构品牌”，相关权利归原权利人。AI 标识按适用平台规则落实，话题标签不能替代它。

《已就寝》的正文示例：

> 21:14，看班监控里，儿子又趴在最后一排睡觉。
> 我让班主任把他拽起来，不行就让他去后面站着。
> 22:12，学校公众号提醒我：他没就寝。
> 班主任说，宿管看着他躺下了。
> 可监控里，熄了灯的教室，他还在那个墙角站着。

置顶评论写法示例：“{核对发布版时间点} 他发来‘妈，我洗漱完上床了，别管了’。可 {核对时间点} 声音一打开，他的手机明明在教室里、在他裤兜里响，人一动没动。那条消息是谁发的？”这里只示范写法，时间必须从本次成片核对，不照抄示例。

## 交付清单

完整任务交付成片（含 3.5 秒观看提示）、无提示副本、3:4 主封面和备选、发布文案、视觉脚本、资产板与确认记录、制作项目 README 修改记录。先核文件存在、可打开与规格，最终每个文件一个链接，写时长、规格和本版改动；只要求部分阶段时只交实际完成内容。声音未选定则先单独交试听，不把待确认片报为最终版。文案交付不等于代发授权，实际发布按当前用户授权处理。

## 分享物料（用户要求时再做）

**图文卡片**（比如拆解某一期的工作流和提示词）：从成片按时间点抽关键帧，裁出实拍画面区域；用 HTML 写 1080×1440 的多张卡片，Playwright 逐张截图，检查文字有没有溢出；先拼总览图检查字号，再打包成 zip。

**小红书笔记**：标题不超过 20 字，正文按“结果 → 方法 → 提示词 → 互动”写，配图用卡片。

**头像与主页背景**：头像应符合原创人物或账号定位；背景按平台规格裁切，先检查主页显示效果。
