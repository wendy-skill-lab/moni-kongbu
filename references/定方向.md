# 第一到第三步：定方向、挖恐怖要素、定视觉呈现

按“场景 → 恐怖要素与大纲 → 最恐怖的画面”一层层收窄，再写完整剧情。每层只让用户确认一个决定；用户已经给出的层原样保留，从缺失层继续。下面的公开范例用于讲方法，不是默认候选，也不构成真实事件。

## 0. 开场：先问用户觉得什么最恐怖

只在从零创作时使用开场；审核、发布、更新 Skill 或续做已有项目时，先按 `SKILL.md` 的入口路由。第一条创作回复不先搜索市场，不先讲流程，直接问一个问题并给约 6 对“场景 × 元素”：

```text
你觉得最恐怖的是什么？下面每一条是一个场景和它里面那个让人发毛的东西。
挑一条，或者说一个你自己觉得最恐怖的场景或东西，我帮你配上另一半。

**1. {场景} × {元素}**
{2–3 句：“我”是谁、在哪；隔着手机用什么看到；哪一点不对。}

**2. …**（约 6 对）

都不想挑，就回“你定”，我推荐一个。
```

配对规则：

- **天然关联。** 元素是场景里原本就存在、会让人发毛或带现实情绪的人、物、动物、声音、数字或记录，不必本身是鬼。不要把场景和元素拆成两组无关清单。
- **看得见制作形态。** 每对写出“我”如何隔着手机看到，设备不限摄像头，照片、App、门锁记录、地图、通知都可。
- **拉开类别。** 在家里、公共场所、工作场所、交通工具、户外等空间中跨类选择；元素、设备和主角关系也变化，不把所有选项写成“夜里在家看摄像头”。
- **每次换。** 本轮下一批不重复前一批，先查自己的项目 `选题记录.md`。文档范例不原样充当新方向，也不从公开版推断作者做过哪些其他项目。可结合用户明确给出的季节或处境，不编造时事背景。
- **守硬规矩。** 每对只写同一晚、同一主空间；全程是“我”的手机，“我”只看见怪事；靠打字和系统字段推进，正常人声最少。

用户要更多时给 10–12 对，按空间类别分组，与已给的不重复；末尾推荐 3 个，每个一句理由。不要承诺选题一定走红。

| 用户给的 | 下一步 |
| --- | --- |
| 挑了一对或自己给了一对 | 写场景卡请其确认，进入第 2 节 |
| 只给场景或元素 | 配另一半，给 2–3 对并推荐一个 |
| 一个画面、设定或参考视频 | 复述成三层，已有层保留，从缺的层开始 |
| “你定” | 推荐一对，一句理由，请确认 |
| 都不喜欢 | 只问不喜欢在哪，再换一批 |
| 想看外部参考 | 读 `找参考.md`，只学机制，之后回到本流程 |

## 1. 场景卡：空间 + 设备 + 处境

用户挑定配对后，给一张轻量场景卡，不急着交完整方向卡：

```text
### 第一步收尾：场景卡
**场景：{空间} · {设备}**
- 空间：主空间，关键门窗、家具与人物方位
- 设备：装在哪、拍向哪，或记录什么；“我”为什么会打开
- 处境：“我”是谁，为什么此刻只能隔手机看、主要打字；主空间里有谁
- 时间：同一晚几点到几点，连续推进
- 现实情绪与代入：为什么不放心，会想分享给谁
- 天然恐怖要素：2–3 个，先保留用户挑的元素
```

尽量让设备与处境天然绑定。不要为凑两种招牌硬塞熟人或人群；若场景适合，再安排熟人关系与群体。诡异主要发生在一个空间，其他空间只作主角此刻所在之处或对话提及。人物位置、门窗、机位提前写清，第五步画成方位图。

**同一时空**允许连续越过午夜，但不跳到白天或几天以后；回看只到同一晚更早的记录。**第一视角**要求每份证据都能由“我”手机打开，不出现另一个“我”、主角被复制或监控中出现主角自己。**文字为主**要求主角不发语音，配角也优先打字，实拍里的人不正常聊天。

### 公开范例：学习漏斗，不复制设定

| | 《宝宝一直在笑》 | 《已就寝》 |
| --- | --- | --- |
| 现实处境 / 场景 | 妈妈出差，靠婴儿房看护器远程看娃 | 家长在手机上看住校孩子晚自习 |
| 恐怖要素 | 婴儿的反应与在家带娃的熟人 | 监视、服从与整齐划一的孩子 |
| 最恐怖的画面 | 爸爸脸贴墙站在墙角，识别圈写“爸爸”，停留 4 小时 32 分 | 熄灯后全班坐得笔直、双手叠放、一起张嘴背书，抬头率 100% |
| 设备 | 看护器夜视实时画面 + 识别圈 | 家校看班监控 + 检测框与人数 |
| 怎么发现 | 云台转到平时拍不到的地方 | 未就寝推送 → 问老师 → 自己打开监控 |
| 主 / 辅空间 | 婴儿房 / 主角住的酒店 | 教室 / 对话提及的宿舍 |

共同做法是现实处境 → 自然存在的设备 → 与人话对不上的证据 → 冷静的系统字段。“熟人背对镜头站墙角”不是公式，新片不要复用这一标志画面。两种招牌机制可重复，具体动作、证据与发现过程要变。

### 设备与记录不限于摄像头

可使用家用监控、婴儿看护器、学校看班、车内摄像头、行车记录仪、门铃、送达照片、扫地机器人避障照片、红外相机、热成像、无人机、手机夜景/实况/连拍/延时、视频消息、回放或录像带。也可用声音、数据和文字记录；完整载体见 `恐怖怎么表达.md`。

每种载体都须满足：设备在处境中自然存在，功能有现实依据，“我”此刻能打开，观众能拿到非聊天证据。真实产品功能与截图只作研究依据；虚构 App 用原创名称，素材复用另核权利。

## 2. 挖恐怖要素，摸出大纲

恐怖要素是场景里本来就有、平时让人发毛或带现实情绪的人或物。顺着用户给的词挖，不另起炉灶：

1. 这个地方独处时，什么最让人不舒服？
2. 现实情绪是监视、控制、孤独、愧疚还是不放心？
3. 设备平时记录什么，哪个字段“差一点”就不对？
4. 谁应该在、谁不应该在？熟人和群体是否自然存在？
5. 最小异常是多一个、少一个、过于整齐、重复、位置或声音不对？

默认给三个方案：**群体一致得不正常、熟人不对劲、两者组合**。两种机制不因上期用过而避开；不适合当前场景或用户要换口味时，从其他 12 种挑主表达。其余机制平时可作辅助证据。每期变化的是场景、动作、证据、关系和揭示，不只是设备。

```text
**方案 N：{一句话标题}（主表达：…；辅助：…）**
- 发生了什么：2–4 句，具体画面、字段与冲突
- 为什么本身就吓人：一句

推荐方案 X：{一句理由}
{5–7 行带时间的粗大纲}
```

大纲按轻松开场 → 第一次直给证据 → 升级 → 矛盾点 → “快要给了” → 戛然而止写。每行带同一晚的时间，先定结尾方向，第四步再细化。不细剖全部剧情，留给用户修改。与自己的旧作品相近时，加一句说明这次换了哪些动作、证据和结构。

**公开范例的大纲写法（《已就寝》，不是候选）：**

```text
21:14  课堂状态提醒，点开看班发现孩子趴桌
21:15  打字请老师去叫他，监控显示他走到后墙角
22:12  未就寝提醒，老师却说晚自习结束已经回去
之后   自己打开监控，他还在；视频打过去，裤兜在响
之后   墙角空了，全班坐直齐声背书
最后   他文字回复“你听，我在背书”，在最快处断掉
```

## 3. 定恐怖点的视觉呈现

把要素落成观众亲眼看到的那一帧或亲耳听到的声音。先用 3–4 行写共同画质：设备、机位高度、灯光/红外、时间与机位名，参照 `实拍质感.md` 第 5 节。再给约 3 种具体呈现：

```text
### 呈现 N：{标题}
- 画面：具体动作或异常状态，发生在空间哪里
- 机位和灯：设备装在哪、拍向哪，哪几盏灯亮着
- 怎么发现：设备怎么动、放大/回放怎么做，或和平时怎么对照
- 字段：画面与 App 上的原文
- 第一遍看到什么；回看会发现什么
- 为什么能当封面
```

动作小、慢、幅度低；源头不露全貌，不突脸。人物可以完整出现，但不能把清晰鬼脸当证据。实拍里不靠正常聊天推进，人声只留给诡异本身。用户问“看到了什么”，回答位置、姿势、字段与变化，不讲抽象寓意。

推荐一个并说明理由，如一个机位能完成、与大纲吻合、证据一眼可读。指出需随之微调的大纲，用户认可后再进第四步。确认的标志画面兼作封面底图。

## 完整方向卡（用户想一次看完整方向时）

用 P1d 一次给 3–4 个完整方向，最后推荐一个，不把完整卡片当默认开场：

```text
### 方向 N：《片名》　A/B/C 类
- 画面展现场景：空间 + 设备 + 处境
- 恐怖要素：场景里本来就让人发毛的人或物
- 最恐怖的点：具体画面或声音、位置、字段原文
- 主表达 / 辅助：编号见 恐怖怎么表达.md
- 怎么呈现：设备、机位、动作或对照
- 场景：主空间 + 辅助空间 + 同一晚的时间
- 现实处境与一句话钩子
- 人物：“我”是谁，跟谁打字
- 粗节拍：5–7 行
- 矛盾点、结尾事实与封面画面
```

A 为聊天主线穿插设备，B 为开头先给异常，C 为单一监测器界面；按用户目标选，不强制每片照搬 A 类。两种招牌可出现在多个方向中，但动作和证据各不相同；至少给一个痕迹、声音、文字、数据、位置或规则主导的替代选项。把恐怖点并排看，只换设备就能互换的，重想。片名通常 2–5 字，像一句话或一个系统字段。

## 讨论方式与常见错误

保留用户的原话和设定，只补空缺，简记补充逻辑；每版另存。用户尚未确认方向和要求写脚本时，不跳写正式脚本；脚本未确认，不生成素材。卡住时只补当前层：没方向用开场配对，有场景挖要素，有要素给具体画面，有画面定骨架，结尾收不住给 3–4 个结尾方案。

避免开场泄露全部异常、跨天跳叙、上帝视角、主角变成怪物、正常对话过多、系统无铺垫替角色收尾、只聊天没有证据，以及只换设备不换动作证据。角色自然出现，线索可回看，结尾停在前面已铺垫的事实。
