# 真实感：怎么让画面像真的手机录屏

这份文档提供通用的手机界面、设备画面与声音制作规范。参数已写进模板；新界面先查真实产品截图。

**总原则**：界面布局、交互和设备行为应可信；虚构 App 使用原创品牌名，显著标注作品为虚构演绎。

## 1. 画布和比例

成片 1080×1920、30 fps、9:16。引擎逻辑画布为 393×699，以适配竖屏平台并保留线索可见性。

抖音会挡住三块地方：右侧的点赞、评论、转发按钮栏（大约右边 15%）、底部的标题和文案区（大约下面 20%）、顶部的搜索栏。群名、系统字段、关键线索都不要放进这三块。

## 7. 实拍画面怎么做得像真的

**完整做法见 `实拍质感.md`**：判断标准（和真实截图并排分不出来）、九条要素、各设备画质卡、提示词写法、`scripts/cctv_look.py` 后期、三种审片看法。这一节只留概要和常见问题。

**先做母版，再改变体。** 先生成一张固定机位的“母版”（比如高中教室晚自习的斜侧机位），两个模型各出几张候选，挑最平淡、最像真监控的一张。之后所有变体（趴睡、老师拍肩、面壁、熄灯夜视）都在母版上用图像编辑改，机位一点都不能动。

**机位**：斜侧、略低、能看到全景；家用监控就是天花板角落俯拍。

**内容**：平淡、日常，只有一处不对劲，不要电影感的光影。

**常见画面问题**：

| 问题 | 规则 |
| --- | --- |
| 逼近镜头的人脸是一团纯黑 | 让他一直低着头，只露头顶和头发 |
| 主角身上有一团淡淡的影子 | 不要。主角就是一个正常趴着的学生 |
| 黑影是“圆不隆冬的黑东西” | 必须看得出是人形剪影，半透明，只留约三成暗度，边缘模糊、去色（`scripts/soften_figure.py --keep 0.3`） |
| 场景照片太像摆拍 | 要像真的用手机拍的：视角压低、随手构图 |
| 老师拍错了人 | 动作位置要和方位一致，静帧阶段就核对座位 |
| 全班说是在背书，嘴却没动 | 换能做出嘴部开合的视频模型，并逐帧放大检查嘴真的在动 |
| 视频机位和定稿全景不一致 | 视频首帧必须就是定稿图；换素材后先和定稿图并排对比 |
| 检测框不动 | 人的头会轻微浮动，框要跟着动 |
| 监控画面“太好看”、像渲染图 | 光线不合时间、没有过曝、没有噪点和压缩、没有广角畸变、主角居中。按 `实拍质感.md` 重写提示词，再过 `cctv_look.py` |

**视频**：用母版做首帧，需要从 A 状态变到 B 状态时再加尾帧；动作慢、幅度小、镜头锁死、不往前推。

**不是监控、也不是人的记录，怎么做得像真的。** 主表达换成痕迹、声音、数据、位置时，“直给的证据”就是下面这些东西，真实感同样要抠：

| 记录 | 怎么做得像真的 |
| --- | --- |
| 手机照片（随手拍、人像、夜景、实况、连拍） | 构图随意，有一点手抖；人像模式的背景虚化边缘有抠图痕迹；夜景模式暗部有涂抹感、灯有光晕；实况照片长按会动 1.5 秒左右，带一点声音；相册“详情”里有拍摄时间和地点。藏的东西只占画面很小一块，放大才看得清 |
| 热成像 | 铁红或白热色板，分辨率低、有块状像素；有中心点和最高温光标、可见光画中画、录像计时。先做一张灰度“温度图”再套色板，人形的轮廓、温度、位置都能精确控制。人形只是一团温度，没有五官 |
| 录音、语音、转写 | 波形要和声音对得上，“一条平的波形却转出了文字”本身就是证据；转写有说话人编号，偶尔有错字；语音条有时长和未读红点 |
| 数据记录（门锁、门禁、水电表、传感器、打卡） | 照真产品的字段和措辞，时间精确到秒，列表按时间倒序；最好有平时的对照（一周的柱状图、往常的相似度），观众才看得出今晚哪里不对 |
| 地图、位置、轨迹 | 照真实地图和配送 App 的版式，地名、店名全部虚构；距离数字不要匀速变化，有停顿、有回退；轨迹线有 GPS 漂移 |
| 识别标签、计数 | 置信度、相似度小幅浮动，不要整齐的 1.00；标签措辞冷静、像产品（“类型：人”“检测到新的家庭成员声音”） |

这些界面同样**由界面层画字**，图像模型只出底图（照片、热成像底图、地图底图）。

## 8. 声音

**只用剧中真实存在的声音**：家里或教室的夜间底噪、解锁和锁屏、按键、收到提示、通知、语音条、电话铃、设备麦克风收到的声音。**不加配乐，也不加惊吓音效。** 最吓人的地方往往是完全安静（《宝宝一直在笑》里“转过来了”出现时全片静音）。

| 声音 | 规则 |
| --- | --- |
| 监控声 | 只有监控画面在前台、而且点开了喇叭时才有声音（电流声、房间声）；切走就断，卡顿时静音 |
| 手机外放、通话 | 窄带（300–3400 Hz）加压缩，像从手机小喇叭里出来 |
| 裤兜里的来电铃声 | 自己合成，闷在布料里；裤兜里的光跟着铃声同步，响的时候亮、停的时候暗；正式制作先提供试听版 |
| 学校电铃 | 老式电铃，刺耳，响 6 秒左右 |
| 语音条 | 必须听得清；台词自然，先出 3–5 版给用户挑 |
| 哼歌 | 像普通人闭着嘴轻轻哼，不能像美声 |
| 一屋子人背书 | 背的不是真的中文，是打乱的伪文本；全班整齐、同一个节奏、一起停顿；越背越快，在最快处和画面一起硬停；不能有任何一个人的声音突出（`scripts/crowd_recite.py`） |
| 电平 | 以对白为基准（语音条约 -12 dBFS），铃声比语音低约 5 dB；手机界面音不跟着调，按下面的绝对电平加；成片整体约 -20 LUFS（宝宝 -20.4），编码时只加安全限幅 |
| 结尾 | 最后一个声音和黑屏同一帧结束（戛然而止），或者铃声进入黑屏后再响 1.4 秒停 |

### 手机界面音：照《宝宝一直在笑》原版，不要自己做

统一使用 `templates/audio/ui/`，由 `scripts/ui_sounds.py` 在电平锚定后加入混音，避免每期重新合成导致音色和响度变化。

| 声音 | 什么时候响 | 成片电平 | 文件 |
| --- | --- | --- | --- |
| 按键 | 每个拼音字母一下（约 0.1 秒一个）、每次选词上屏一下、按“发送”一下（气泡出现前 0.06 秒）；发送键和字母键是同一个声音 | 峰值约 -11 dBFS，清楚但不扎耳 | `key_click.wav` |
| 发送 | 只有按“发送”键那一下按键声；气泡出现时**不加任何发送音** | — | — |
| 收消息“叮” | 正停在这个聊天里收到别人的消息、App 内弹横幅、锁屏推送；故意要死寂的地方去掉 | 峰值约 -13.5 dBFS | `msg_ding.wav` |
| 触屏点击 | 进出页面、点横幅、点语音条、点按钮，比画面早 0.02 秒 | 峰值约 -20 dBFS | `touch_tap.wav` |
| 划动 | 上滑进桌面、切 App、下拉 | 峰值约 -16 dBFS | `swipe.wav` |
| 锁屏 | 按侧边键 | 随附库基准电平 | `lock.wav` |
| 面容解锁 | 解锁成功时两下轻震 | 随附库基准电平 | `faceid_buzz.wav` |

**不要加发送音**：本模板发送只有发送键的按键声，气泡出现不另加音效。

**做法和验收**：
1. `soundtrack.py` 里只收集时刻（点按、叮、划动、锁屏），在“电平锚定之后、限幅之前”一次加进去：`mix += UI.bus(F, N, taps=taps, dings=dings, swipes=swipes, locks=locks, skip=[(black, 片长)])`。按键（含发送键）的时刻 `UI.bus` 会自己从 `drafts` 算，和引擎的打字排程一致（含每段停顿、`rate`、`hold`）。
2. 不要自己再合成一份按键声，不要用音效模型生成“键盘声”（出来是机械键盘或打字机），也不要改这些声音的音量。
3. 编码后跑 `python3 src/ui_sounds.py check ../<片名>.mp4`：按键“同一个声音”和“电平 ±1.5 dB”两项都 ✓ 才算过。自己量电平时注意：成片是左右相同的立体声，用 `ffmpeg -ac 1` 转单声道会把两个声道按 0.707 相加，读数虚高 3 dB；要按立体声解码再取左右平均（`check` 已经这样做）。
4. 想单独听一遍：`python3 src/ui_sounds.py demo 试听.wav`（打“我到了你呢”、发送、对方回复）。

**声音要给用户挑**：铃声、语音、背书这类最影响“假不假”的声音，每次出 3–5 版。用 `scripts/swap_audio.sh` 把每一版接到成片对应那一段的画面上，做成 720p 试听片段，让用户对着画面挑。

## 9. 片头观看提示和片尾

**观看提示**（固定，3.5 秒，`scripts/warning_card.py` 生成，`encode.sh` 自动接在片头）：黑底；“观看提示”四个字，大号、字距拉开；下面一道细横线；正文四行“本视频含有恐怖、惊悚元素，可能引起不适。心脏病患者、未成年人及易受惊吓者请谨慎观看。”；最下面一行小字“剧情纯属虚构 · 建议佩戴耳机”。淡入淡出各 0.4 秒，这一段静音。

**片尾**：黑屏，然后片名卡（白字片名居中），1–2 秒后结束。

| 实拍画面和真实截图分不出来 | 每个【实拍】机位抽一帧，和 `research/real_refs/` 里同类设备的真实截图并排；`cctv_look.py --report` 没有提示 |
| 母版、变体、视频切换不跳 | 切换点前后各一帧，亮度、噪点、颜色一致 |
| 发送前键盘还在 | QA 帧里每条我方消息发出前一帧 |
| 输入框里的字完整 | 最长的那一句 |
| 抖音遮挡区没有关键信息 | 把成片帧和右侧、底部区域叠起来看 |
| 时钟、电量、人数在往前走 | 抽锁屏、看班画面的连续几帧 |
| 卡顿时 OSD 时间停住 | 卡顿前后各一帧 |
| 面容解锁时段对 | 每次锁屏解锁 |
| 语音和画面同步 | 按语音条播放时刻抽音频的响度，确认对得上 |
| 按键声是随附库基准、没有发送音 | `python3 src/ui_sounds.py check <片名>.mp4`：按键相关 ≥0.85、电平 ±1.5 dB；发送只有按键声 |
| 方位前后一致 | 把同一个空间的所有画面并排看 |
| 写进文件的中文没有多余空格 | 终端粘贴长文本时偶尔会插入空格（如“夜 视”），写完用 grep 查一遍 |
