# 第三步：制作（用户确认视觉呈现脚本之后才开始）

开工前先读 Manus 自带的 video-generation、imagegen、tts-prompter、image-processing 四个技能。新建项目后立刻写 `PLAN.md`，每完成一步就往里追加：素材清单、节拍时间表、关键决定、用户反馈。上下文被压缩后，先读它再继续。

## 1. 环境和新建项目

检查当前环境是否有 Python 3、Node.js、FFmpeg、Chromium 和中文字体。不要假设沙箱路径或系统权限；缺失依赖按当前平台安装，Python 优先使用虚拟环境：

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install numpy pillow opencv-python-headless scipy
bash <技能目录>/scripts/new_film.sh <项目目录> <片名> cctv   # 或 car
```

`<技能目录>` 是当前安装位置或仓库根目录。脚手架复制引擎、示例时间轴、混音、封面、图标和音效；自动安装 Playwright 和 Inter 字体。macOS 没有 `/usr/bin/chromium` 时，运行 `npx playwright install chromium`，或设置 `CHROMIUM_PATH`。FFmpeg 需要支持 rubberband 滤镜，字体需覆盖中文。

## 2. 引擎结构

成片画面就是一个 HTML 页面按时间逐帧截图。`film.html` 由 `film_head.html`（通用的 iPhone 和微信引擎）加 `part.js`（本片模块，结尾自带 `window.setTime` 和 `</script></body></html>`）拼成，执行 `python3 src/assemble.py` 时把片名填进 `{{TITLE}}`。在 part.js 里重新声明同名函数，就能覆盖通用实现。

| 项 | 说明 |
| --- | --- |
| 画布 | 逻辑尺寸 W=393、H=699（9:16）；SAFE=20，键盘高 KBH=276，“+”面板高 PNH=250；渲染时放大 1080/393 倍 |
| 路径 | `A='../assets/'`，`TH='../assets/thumb/'`，`IC='../icons/'` |
| 时钟 | `F.clocks=[[t0,时,分,秒],...]` 分段推进，`clock(t)`、`clockFull(t)`；`F.dates` 是日期标签；电量随 `F.sfx.locks` 递减 |
| 打字 | `draftState(d,t)`，`d={chat,start,send,chunks:[[拼音,汉字,停顿秒?],...]}`，按 0.105 秒一个字母，再按可用时间压缩；`F.decoys[汉字]` 给干扰候选词；键盘出现的时间按打字时长自动算 |
| 消息 | `msgRow(m,t,chat)`：kind 可以是 time、image、voice（play:[开始,结束]，dur）、call 或文本；群聊显示昵称；`F.typing` 是“对方正在输入”；`F.scroll`、`F.plus`、`F.sheet` |
| 锁屏 | `lockView(t,seg)`：`seg.notifs[{app,who,title,body,when}]`、wake、newAt、tapAt；壁纸 `thumb/wallpaper_full.jpg`；面容解锁时段 `F.faceid=[[开始,结束],...]` |
| 横幅 | `F.banners[{t,app,who,title,body,tap 或 hold}]` |
| 段落 | `F.segments` 按类型分发：lock、black、sleep、notifOpen、chat、list、mpOpen、push、pop、svc、kb、vcall、vcallMin…… |

**`module_cctv_kanban.js`（《已就寝》）**：微信列表（下拉出“最近使用”小程序）、带未读数的聊天页、@ 选人面板（群成员铺满一屏，带字母索引）、输入框自动换行（按字宽，最多 4 行，框向上长高）、服务号模板消息卡片、看班小程序（16:9 视频区 y98 高 221、OSD 时间戳、平铺水印、捏合放大、缓冲“加载中”、卡顿冻结、“设备离线”、人数标签、AI 检测框可逐帧跟踪）、回放（时间轴拖动、逐帧、倍速）、微信视频来电与主叫等待页、通话小窗、裤兜光和铃声同步闪。数据都在 `F.kb`：`live`（clip 视频片段、still 静帧、offline）、`over`、`counts`、`zooms[{s,e,z,fx,fy}]`、`det`、`replay`；点击动画在 `F.taps`。

**`module_car_call.js`（《我们到了》）**：车企 App 首页和车内画面、代驾“司乘同显”地图和绕路轨迹、iOS 语音通话界面。

时间轴写在 `src/build_data.py`，生成 `film_data.json`。示例里有 `ME()`（我打字发送）、`HIM()`（对方回复）、`SVC()`（服务号卡片）、`list_tap()`、`buffer()`（卡顿）、`commit_times()` 等辅助函数和检查逻辑。调节奏改 `PACE`（打字速度系数）和每段的停留时长。

## 3. 素材

**界面调研先做。** 动手前上网搜真实截图（提示词 P5），记进 `research/ui_reference_notes.md`，具体到颜色、字号、按钮排布和措辞。微信和 iPhone 的参数已经在 `真实感.md` 里，新的 App 照这个标准调研。

**实拍画面**（manus-tools 的 `generate_image`）：开工前先给每种设备找 2–3 张真实截图存进 `research/real_refs/`（`实拍质感.md` 第 1 节）。先做母版（提示词 P6），两个模型各出几张，挑最平淡、最像真监控的一张。所有变体都在母版上用图像编辑改（提示词 P7），编辑模型和原图的对齐偏差在 1 像素左右。时间戳、检测框、人数不让模型画。用 `python3 src/crop169.py 输入 输出` 裁成 1920×1080。编辑模型会挪动人物，所以不要拿“干净底图相减”来抠黑影，要用 `soften_figure.py` 在编辑图内部估计背景再弱化。

**实拍后期**：未后期的母版留在 `assets/gen/`，给变体和视频当输入；放进引擎的是过了 `scripts/cctv_look.py` 的版本。同一机位的母版、变体、视频用同一个预设和同一组参数。图过了后期，把 `build_data.py` 里的 `NOISE_K` 改成 0.6（看班模块 `IRN()` 动态噪点层的倍率），这层只负责让静帧“活着”。详见 `实拍质感.md` 第 7 节。

**先确认静帧**：母版和关键画面确认后再生成视频。静帧阶段就核对机位、姿势与方位。

**视频片段**（manus-tools 的 `generate_video`，提示词 P8）：未后期的母版做首帧，要从 A 状态变到 B 状态就加尾帧；动作慢、幅度小、镜头锁死。生成后先过后期：`python3 -u <技能目录>/scripts/cctv_look.py clip.mp4 clip_look.mp4 --preset <同母版> --no-distort --fps 15 --stutter 0.02 < /dev/null`。拆帧：`ffmpeg -i clip_look.mp4 -r 24 -vf scale=1280:720 -q:v 3 assets/frames/<名>/f%03d.jpg`，引擎按 24 fps 播放，15 fps 的顿挫会保留。改帧之前先备份到 `assets/frames_orig/`。

视频模型的实测结论：同一张写实的教室夜视图做首帧，minimax 系列能守住机位（零漂移），但全班的嘴几乎不动，只是头在晃；seedance 系列只给首帧时嘴的开合明显，但首尾帧都给同一张写实人物图时，会被隐私过滤拒掉。验收嘴动要看前排的脸逐帧放大，`manus-analyze-video` 会把细微的嘴动判成静止。

**语音**（manus-tools 的 `generate_speech`，提示词 P9）：一个人的几句台词连续录完再切开；高中男生用过 Achird、Umbriel 音色。每条都用 `manus-speech-to-text` 转写逐字核对。手机外放和通话要做窄带处理。

**头像、壁纸、校徽**：生成后裁成 240 像素的方图存进 `thumb/`；壁纸裁成 393:699，存成 1179×2097。用户给的头像先裁掉截图的圆角和白边。

## 4. 检查帧和全片渲染

```bash
python3 src/build_data.py && python3 src/assemble.py
cd src && node render.js qa 0.2,5,10,20.4          # 指定时刻出检查帧 → ../qa/t_*.png
python3 contact_sheet.py qa ..                     # 拼成 ../qa/sheet_*.jpg，逐张看
WORKERS=6 node render.js full                      # 全片 → ../frames 和 ../frames.ffconcat（相同帧自动去重），约 10 分钟
FROM=141.0 WORKERS=6 node render.js full           # 只改了后半段：141 秒之前沿用旧帧，只重渲之后的部分
```

全片渲染放后台（exec 的 background），用 `job wait` 等结果；渲染期间可以并行做封面和文案。只改了声音就不用重渲画面。

## 5. 混音和编码

```bash
python3 soundtrack.py                              # → ../soundtrack.wav（numpy 合成与混音）
bash encode.sh                                     # → <片名>.mp4（含 3.5 秒观看提示）和 <片名>_无提示.mp4
python3 ui_sounds.py check ../<片名>.mp4             # 按键声是不是随附库基准、电平对不对
python3 contact_sheet.py video ../<片名>.mp4 1.5,11,56,123   # 成片抽帧复查
```

混音规则见 `真实感.md` 第 8 节：只用剧中存在的声源，不加配乐和惊吓音效，以对白为电平基准，编码时只加安全限幅。手机界面音（按键、收消息“叮”、点按、划动、锁屏、面容震动；发送只有按键声，不加发送音）一律由 `ui_sounds.py` 的 `UI.bus()` 在电平锚定之后加，示例混音里已经接好；新片只需要把点按、叮、锁屏的时刻收集对，不要自己重新合成按键声。

后台并行跑含 ffmpeg 的 Python 脚本时，必须写成 `python3 -u 脚本.py < /dev/null`：交互式终端里放到后台的 ffmpeg 会去读终端输入，被系统挂起（ps 状态 T），负载为 0、日志为空，一直空等。

## 6. 工具脚本（在 `scripts/` 里）

| 脚本 | 用途 |
| --- | --- |
| `new_film.sh` | 新建项目 |
| `render.js` | 逐帧渲染：`qa` 出检查帧，`full` 出全片，`FROM` 局部重渲 |
| `assemble.py` | 拼装 film.html |
| `encode.sh` | 编码成片并接上观看提示 |
| `warning_card.py` | 生成 3.5 秒观看提示卡 |
| `contact_sheet.py` | 检查帧拼图（`qa` 用渲染帧，`video` 从成片抽帧） |
| `crop169.py` | 把生成图裁成 1920×1080 |
| `soften_figure.py` | 把太清楚的黑影弱化成看不清的人形（`--keep 0.3`） |
| `cctv_look.py` | 实拍质感后期：9 个设备预设（监控彩色和红外、家用摄像头、看护器、门铃、行车记录仪、红外相机、手机夜景），静帧和视频都能处理；`--report` 做画质体检 |
| `track_faces.py` | 固定机位视频逐帧人脸跟踪，让检测框跟着头动 |
| `crowd_recite.py` | 用几条 TTS 声部叠出“一屋子人背书”，5 种风格 |
| `swap_audio.sh` | 不重渲画面只换音轨；或截一段出 720p 试听片段 |
| `ui_sounds.py` | 手机界面音：随附库基准按键声（发送只有按键声，不加发送音）、叮、点按、划动、锁屏、面容震动，按参考基准电平出整条；`check` 验收成片，`demo` 出试听 |

**检测框跟着头动**：

```bash
python3 <技能目录>/scripts/track_faces.py --frames assets/frames/<片段名> --out assets/stills/<片段名>_tracks.json --count 46
```

用 YuNet 模型（`templates/models/yunet.onnx`）在放大 2 倍的帧上检测，按位置把所有帧的检测结果聚类，保留出现在 30% 以上帧里的脸，缺帧插值。找到的人数不够时调低 `--thr`（0.38–0.42）或调高 `--up`（2.5）。时间轴里这样接：

```python
TRK = json.load(open(ROOT / 'assets/stills/W_tracks.json'))
det.append(dict(s=t_in, e=t_out, col=GREEN, stagger=0.03, trk='W', t0=t_in, rate=1, lab='抬头 {sc}', boxes=[]))
kb = dict(..., det=det, tracks={'W': TRK})   # 帧号 = floor((t - t0) * rate * 24)
```

**一屋子人背书**：

```bash
python3 <技能目录>/scripts/crowd_recite.py align --stems stems/ --ref stems/某个声部.wav --out stems_aligned/   # 只有“齐读”需要先对齐
python3 -u <技能目录>/scripts/crowd_recite.py make --stems stems_aligned/ --dur 24 --style unison --phone --out recite.wav < /dev/null
```

五种风格：`chaos`（60 人各念各的）、`crowded`（120 人，更远更闷）、`unison`（齐读，一起停顿）、`reverse`（倒放）、`rising`（越背越尖）。全部都是越背越快、在最快处硬停，没有任何一个人的声音突出。`--phone` 会加上教室混响和手机通话音质。

**声音试听片段**：

```bash
bash <技能目录>/scripts/swap_audio.sh <成片.mp4> <新混音.wav> <试听.mp4> 124 155   # 截成片 124–155 秒，换上新声音
bash <技能目录>/scripts/swap_audio.sh <成片.mp4> <新混音.wav> <新成片.mp4>           # 不给起止就整片换音轨
```

片段里的声音和放进正片的完全一致。每版放进一个“试听”文件夹，文件名写清风格（如 `3_齐读_同一个节奏.mp4`），让用户挑。

## 7. 踩过的坑（每期审片都查）

| 问题 | 处理 |
| --- | --- |
| 字还没打完键盘就收起（6 处） | 键盘出现的时间按实际打字时长算，构建脚本里断言发送早于键盘收起 |
| 长句把输入框里的字截掉 | 输入框按字宽换行、向上长高 |
| 锁屏解锁太假 | 还原苹果的解锁动效和滑动音 |
| 抖音界面挡住群名和线索 | 比例对齐 9:16，关键信息避开右侧和底部 |
| 数字不变 | 时钟、电量、人数随剧情推进 |
| 卡顿时时间戳还在走 | 冻结时 OSD 停在同一秒，恢复后跳过去 |
| 面容解锁取错时段 | 取最近的一次（reverse 以后 find） |
| 逼近镜头时脸是一团黑 | 编辑成深低头只露头顶，再羽化合成回原帧 |
| 黑影太明显 | `soften_figure.py --keep 0.3` |
| 语音和画面不同步 | 在成片里按语音条播放时刻抽音频响度，确认对得上 |
| 换了视频素材，放大对不准人 | 放大原点 fx、fy 要按新画面重算，可见范围是 [fx − fx/z, fx + (1−fx)/z] |
| 换了背书素材，全片其他部分整体变小声 | 混音以背书段为基准时会出现，换素材后逐段对比上一版电平 |
| 后台 ffmpeg 一直不动 | `< /dev/null` |
| 写进文件的中文多了空格 | 终端粘贴长文本时偶尔插入空格，写完用 grep 查一遍 |

## 8. 版本管理

每次按用户反馈改片，都在项目 `README.md` 的修改记录里写清改了什么、为什么改。旧版本改名留档（如 `已就寝_v10a.mp4`、`build_data_v10b.py`），不要直接覆盖。成片文件名始终是 `<片名>.mp4`，方便用户在侧边栏里直接看最新版。
