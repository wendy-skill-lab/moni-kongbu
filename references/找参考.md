# 找参考（可选：用户要“今日参考”或每日简报时用）

## 1. 找 5–8 条参考（优先近 7 天新发，其次近 30 天高赞）

**第一步：云端浏览器刷抖音。** 打开 `https://www.douyin.com/search/模拟恐怖?type=video`，按“最新发布”和“最多点赞”各看一遍；再搜伪人、细思极恐 手机录屏、微信聊天 恐怖、监控 恐怖、规则怪谈、模拟恐怖 智能家居。没登录时搜索结果只显示灰色占位框；遇到占位框、登录或验证码不要硬刷，在简报里写明“今天抖音未登录，参考来自搜索引擎收录的抖音视频页”，改走第二步。

**第二步：搜索引擎找已收录的视频页。** 用 bright-data 的 `search_engine_batch`（Bing，`time_range: week`）搜“<关键词> 发布在抖音 已经收获了”，取 `douyin.com/video/<19 位数字>` 这类链接。**摘要里的点赞数严重虚高，不能直接用**：同一个作者的多条摘要写着同一个点赞数，基本就是账号总获赞。

**第三步：逐页核实，以页面数据为准。** 用 bright-data 的 `scraping_browser_navigate`（`country: CN`）打开 `https://www.douyin.com/video/<id>`，等 8–10 秒后 `scraping_browser_get_text`，能读到点赞、评论、收藏、转发、发布时间、作者粉丝、简介、热评和“推荐视频”栏。显示“视频数据加载中”就换下一条。没有简介时用 `scraping_browser_screenshot` 截播放画面确认形式。

**第四步：顺藤摸瓜。** 有用的新片几乎都来自视频页的“推荐视频”栏，搜索引擎只是入口。`scraping_browser_get_html` 的结果会存成文件，用 Python 正则 `/video/(\d{19})` 提取推荐栏链接，视频 ID 越大发布越新。

每条记下：标题、作者、链接、点赞、评论、收藏、转发、发布时间、形式（聊天录屏、设备界面、监测器、录像带、直播回放、规则逐条），以及一句话机制。拆解时回答：最恐怖的点是哪个画面？证据是什么？判决由谁说出来？评论区在忙什么（解谜、报平安、玩梗）？它靠什么被转发？**只学机制，不抄人物、头像和台词。**（提示词 P15）

## 2. 每日简报的格式

| 部分 | 内容 |
| --- | --- |
| 来源说明 | 今天是刷到的还是搜到的 |
| 参考表 | 标题、作者、链接、数据、日期、形式 |
| 各条机制 | 每条一段 |
| 当日观察 | 3 句话的共同趋势，加一个别人没做、我们能做的空位 |
| 3–4 个方向 | 按 `定方向.md` 的方向卡片格式 |
| 推荐 | 一句话推荐，请用户挑或改 |

简报存成 `YYYY-MM-DD_选题简报.md`，新方向追加到选题记录（追加前用 grep 查重，防止重复追加）。发给用户的消息里只放精简版和文件链接，并写明“你选定前我不开始制作”。当前请求需要简报时先交付简报；未来定时推送需另行配置。
