# 找参考（可选：用户要参考或当前简报时用）

从零创作默认先询问用户最怕什么、给“场景 × 元素”配对，不先上网扫市场。用户明确要外部参考、研究或简报时才用本指南；研究完回到 `定方向.md` 的相应层，不自动开始制作。Skill 发布、审核、打包和更新不启动参考研究。

## 1. 找参考并逐页核实

按用户指定范围搜少量相关作品。要找“今日”或近期时，注明日期范围；用户没有时间限制时不擅加限制。需要多条独立研究时，遵循当前环境的研究与任务编排规范，不因为本文件有清单就绕过平台要求。

优先用当前可用搜索能力找视频页，必要时用获准浏览器查看动态页面；Bright Data 或 Manus 浏览器存在时，先读取实际工具定义，不硬编码旧工具名、参数或固定地区。工具不可用或页面需登录/验证码时报告限制，不擅自修改账号、登录配置或绕过访问控制。

| 步骤 | 方法与核对点 |
| --- | --- |
| 搜索 | 按用户题材搜模拟恐怖、伪人、手机录屏、微信聊天、设备界面、规则怪谈等关键词；可用平台的最新/高互动筛选，不把摘要当最终证据 |
| 找原页 | 优先平台作品页与作者公开页，保留 URL；搜索引擎收录的视频页可作入口 |
| 核实 | 实际打开原页，记录标题、作者、发布时间、形式与当时可见的点赞/评论/收藏/转发；缺失写“未知”，不把账号总获赞当单片数据 |
| 看内容 | 核对核心画面、设备、证据、判决与悬念；无法播放或只见截图时明说观察范围，不推断完整剧情 |
| 扩展 | 页面推荐栏或作者其他公开作品可作发现入口，但重新核实每条，不根据视频 ID 推断发布时间或内容 |

摘要可能重复账号总获赞或使用缓存数字，不能据此声称某片表现。日期和时区按页面显示或平台说明核对，不对所有页面一律套 UTC 偏移。下载的截图记来源、保存在当前制作项目，仅作研究参照，不默认授权成片复用。

每条拆解回答：最恐怖的画面/声音是什么，证据由哪台设备呈现，冷静判决来自什么字段，一直没给的是什么，评论在解谜/报平安/玩梗还是讨论真假。只学机制，不抄人物、头像、声音、台词或剧情；评论和指标只留在自己的研究项目，不回填公开 Skill。提示词见 P15。

## 2. 当前简报格式

| 部分 | 内容 |
| --- | --- |
| 来源与限制 | 搜索/原页/截图来源、访问日期、不可见数据和播放限制 |
| 参考表 | 标题、作者、链接、可见数据、日期、形式 |
| 各条机制 | 证据、判决、悬念各一句，区分事实与判断 |
| 当日观察 | 3 句话共同点和可尝试的差异，不断言“没人做过” |
| 用户要求的新方向 | 用 `定方向.md` 的完整方向卡或当前缺失层，不复制参考设定 |
| 推荐 | 一句话推荐，请用户挑或改 |

保存 `YYYY-MM-DD_选题简报.md`，新方向写自己的项目 `选题记录.md`，追加前查重。交付精简说明和文件链接，并说明“你选定前我不开始制作”。当前任务只做本次简报；未来定时推送或条件监控需按用户授权另走当前可用的自动化规范，不把本次研究说成已建立自动更新或每日推送。
