## 定方向

P1 是从零创作的开场；P1a–P1c 逐层收窄，用户确认后才到下一层；P1d 只在用户要一次看完整方向时用。审核、发布或更新 Skill 不使用创作提示词。所有方向守同一晚连续时间、一个主空间、“我”的手机第一视角、文字主导和最少正常人声。

### P1　开场：最怕什么与配对方向

```
请写一条原创模拟恐怖短片的开场消息，直接问“你觉得最恐怖的是什么？”并给约 6 对“场景 × 场景里让人发毛的元素”。
每对 2–3 句，写清“我”是谁、隔着手机用什么看到、哪一点不对。元素天然属于场景，可为人、物、动物、声音、数字或记录，不必是鬼。设备不全是摄像头。
跨家里、公共场所、工作场所、交通工具、户外等空间与不同元素类型挑选，不把场景和元素拆成两组。每对只写同一晚，靠文字与系统字段推进；“我”只是看见怪事的人，没有另一个“我”或复制主角。
本轮已给选项：{无或列表}；本项目查重记录：{只提供自己的相关记录}。
不要原样拿技能范例当候选，不搜索市场，不先讲流程。末尾写“都不想挑，就回‘你定’，我推荐一个。”
若用户明确要更多，则给 10–12 对、按空间分组，末尾推荐 3 个，每个一句理由。这里只写选项，不写正式脚本、不生成素材。
```

### P1a　补配对与场景卡

```
用户给的方向：{原话}。
只有场景或元素时，先补另一半，给 2–3 对并推荐一个；已有完整配对时写一张场景卡：
- 空间与关键方位
- 设备、机位或记录方式，为什么主角会打开
- “我”是谁，为什么隔着手机看、主要打字；主空间里有谁
- 同一晚的时间、现实情绪与代入关系
- 2–3 个天然恐怖要素，先保留用户选的那个
用户自带画面或设定时，复述成“场景 + 恐怖要素 + 最恐怖的画面”，已给层原样保留，缺哪层补哪层，不推翻重来。
不要为凑机制硬塞人物，不写剧情细节；请用户确认后再收窄。
```

### P1b　恐怖要素与 5–7 行大纲

```
确认场景卡：{原文}；用户线索：{原话}。
挖这个场景里“差一点不对”的最小异常，默认给三个方案：群体一致得不正常、熟人不对劲、两者组合。不因上一期用过而避开这两种招牌；场景不适合或用户要换口味时，从其余机制选主表达。
每个写主表达/辅助编号、“发生了什么”（2–4 句具体画面、字段与冲突）、“为什么本身就吓人”（一句）。推荐一个，一句理由，附 5–7 行带同晚时间的大纲：轻松开场 → 直给证据 → 升级 → 矛盾点 → 快要给了 → 戛然而止。
点到为止，保留用户修改空间。每期换场景、动作、证据和揭示，不只是换设备，不再用“背对镜头站墙角”当新片标志画面。机制编号见 恐怖怎么表达.md。
```

### P1c　最恐怖那一帧的视觉呈现

```
确认恐怖要素和大纲：{原文}。
给约 3 种具体视觉呈现。先写共同画质（设备、机位高度、灯光/红外、时间和机位名），每种写：
- 具体动作或异常状态，在空间哪里
- 设备装在哪、拍向哪，此刻哪些灯亮着
- 怎么通过设备动作、放大、回放或对照发现
- 系统字段原文
- 第一遍与回看分别看到什么
- 为什么能当封面
动作小而慢，源头不露全貌，不突脸；画面必须是“我”的手机此刻能打开的。“我”不在证据画面中出现，实拍里的人不正常聊天。
推荐一种，写理由及大纲需微调之处，请确认后再写完整脚本。
```

### P1d　一次出 3–4 个完整方向

```
你是一个原创竖屏“模拟恐怖”短片账号的编剧。这个账号的差异化是：每一期都有一段“直给”的、像真机留下来的记录（监控、照片、录像、录音、门锁记录、地图都可以，不限于摄像头），由冷静的系统字段说出不对劲，从不突脸。

底层原则（不规定画面长什么样）：
1. 恐怖的源头不给全貌：只给它留下的痕迹、读数、温度、轨迹、声音、动物的反应，或者一个被借走的熟人；不出现看得清五官和全身的鬼。
2. 观众要亲眼看到或亲耳听到一份证据，来自一段非聊天的真实记录。
3. 揭示靠“动起来”（云台转动、捏合放大、回放逐帧、相册上翻、长按实况照片）或者“对照”（平时 98%，今晚 63%）。
4. 两个信息对不上：人说的话和记录里的事实对不上。
5. 结尾戛然而止，回看只推到同晚更早的时刻，不解释，也不写“我也被附身了”。
6. 同一时空：一个主空间加辅助空间，同一晚连续推进，可过午夜但不跳到第二天或很久以前。
7. 第一视角：只给“我”手机此刻能打开的内容，不切别人手机或上帝视角，不复制主角，不让监控或照片里出现“我”。
8. 文字为主：“我”不发语音或在通话说话；配角正常短语音至多一两条且带线索；实拍里不正常聊天，人声只留给诡异本身。

恐怖从哪来（每个方向挑 1 个主表达，可以再加 1–2 个辅助）：
①两个信息源打架 ②系统冷静地下判决 ③看不见的东西留下了痕迹 ④照片或录像里多了点东西 ⑤声音不对 ⑥文字和打字的恐怖谷 ⑦规则、须知、备注 ⑧位置、距离、轨迹 ⑨一群人一致得不正常（招牌）⑩动物或婴儿看得见 ⑪设备自己在做事 ⑫熟人不对劲（招牌）⑬被看见：它也看见了你 ⑭时间对不上：同晚早些时候它就在了
要求：招牌可出现在多个方向里，但动作和证据各不相同；至少留一个痕迹、声音、文字、数据、位置或规则主导的替代选项。不要复用“熟人背对镜头站墙角”；只换设备就能互换的恐怖点重想。

{可选：用户给的场景或灵感}
自己的已做或已提方向（避免重复）：{粘贴当前项目 选题记录.md 里的片名}

请给出 {3/4} 个方向。每个方向写：
- 片名（2–5 字，像一句话或一个系统字段）和类别（A 聊天主线穿插设备 / B 开头就给吓人的东西 / C 只有一个监测器界面）
- 画面展现场景（空间 + 设备 + 处境）与恐怖要素
- 最恐怖的点：一个画面或一个声音，写清观众具体看到、听到什么，在空间的哪里，系统字段的原文
- 主表达 / 辅助：用上面的编号
- 怎么用视觉呈现：哪种设备、什么机位、怎么“动起来”被发现
- 场景：主空间、辅助空间、时间（几点到几点）
- 现实处境：观众为什么代入，会转发给谁
- 一句话钩子
- 人物：主角“我”是谁，在跟谁聊天（微信备注、关系）
- 粗节拍 5–7 行：轻松开场 → 第一次直给画面 → 交替升级 → 矛盾点 → 戛然而止
- 矛盾点：我发现什么不对劲、怎么质问、诡异怎么发生
- 结尾停在哪个事实上
- 封面画面
最后推荐 1 个，写一句理由。
禁止：伪造新闻、警方、官方通知；血腥；突脸；未成年人受伤害的画面；温馨煽情的设定。
```

## 写脚本

### P2　视觉呈现脚本

```
请把选定的方向写成“视觉呈现脚本”。这份脚本是给制作用的，重点是每一段画面怎么呈现。

格式：
# 《{片名}》视觉呈现脚本
竖屏 9:16，全程是 {主角} 的 iPhone 屏幕录制，片头 3.5 秒观看提示，时间按含提示的版本计算。
## 人物（表格：角色 / 微信备注 / 头像画面内容 / 一句话说明）
## 场景与方位（主空间的机位、门、窗、墙角、主角的位置；辅助空间；时间）
## 用到的界面（具体到 App 和页面）
## 分段
每段写：段号、时间段、标题；“画面：”写屏幕上是什么、怎么动、点了什么；对白用“> 角色：内容”；直给画面标【实拍 ①】，写清机位、质感、谁在哪、系统字段原文、那一处不对劲；“声音：”写这一段能听到什么。
## 结尾（最后一个画面、最后一个声音、黑屏后有什么）
## 素材清单（静帧、视频、人声必要性与线索、音效，各自用在哪一段）

结构：前 15 秒轻松，从微信打字聊天开始，最好带一张图片并藏回看线索；然后直给证据；聊天和画面交替升级；“我”打字质问后异常发生；最后戛然而止。

要求：
1. 每次切画面都要有由头（推送来了才点开、问完人才自己去看）。
2. 方位前后一致，机位不动。
3. 数字随剧情推进（时钟、电量、人数、计时）。
4. 对白像真人聊天：短句、语气词、一句话拆成几条发、不交代彼此早就知道的事。
5. 剧中人的反应合乎常理；一段说清楚了就往下走，不写来回解释。
6. 恐怖的源头不能被看清，只能从它留下的东西里感觉到：系统字段、痕迹、读数、阴影、声音、动物的反应。按方向卡片上定的主表达来写，不要自动换回“熟人站在墙角”。
7. 保留用户确认的骨架与原话；只补台词、推送、群成员、数字、杂物、第二层线索，旁边说明补充逻辑。
8. 时间同一晚连续推进，回看只到今晚早些时候。
9. 每段都是主角手机能打开的内容，不切他人手机或上帝视角，不复制、附身主角，不在监控或照片中出现主角。
10. “我”不配音；配角正常短语音至多一两条且带线索；实拍不正常聊天。列出每处人声和必要性，其余都靠字。
开头增加：恐怖要素：{第二步确认}；最恐怖的画面：{第三步确认}。
用户确认这份脚本后才做第五步资产，不直接生成视频。
```

### P2b　结尾方案

```
已确认的骨架与矛盾点之前的脚本：{粘贴}。
给 3–4 个结尾，每个写最后一个画面、最后一个声音、停在哪个事实上、回看能验证的伏笔。缺伏笔就说明前面要补哪条。
可以角色文字回复接追问、一个声音收住、来电未接后铃声停、最快或最近处硬断，或回看同晚较早记录。
不要系统无由头下结论、解释来龙去脉、主角被附身或复制、跳到第二天/很久以前、突脸。推荐一个，请用户确认。
```

### P3　对白改成人话

```
下面是一段手机聊天对白，请改得更像真人在微信上打字：
{粘贴对白}

规则：
- 删掉所有“交代设定”的句子，人不会告诉对方双方都知道的事。
- 长句拆成 2–3 条连发；句尾少用句号，可以用空格断句；可以有“？”“。。。”“啊”“哈”“我去”。
- 先回情绪，再回内容；可以只回一个“？”。
- 称呼按关系来：夫妻叫“老公”“老周”，同事叫“小许”，家长群里叫“陈默妈妈”，代驾叫“师傅”。
- 要发图的地方写成“（发一张{图片内容}）”。
- 正常对白改为打字，主角不发语音；只保留已经确认、带线索的极少配角短语音与诡异本身的人声。
保留原来的剧情信息点，不加新剧情。输出改写后的对白，每处改动后用括号写一句原因。

示例：
原句：“我是今晚值夜班的护士，我们科室最近发生了怪事。”
改后：“小许，你是不是忘了什么（发一张工牌照片）”“我去！工牌忘拿了”
```

### P4　脚本自检、审片自检

```
请按下面 16 条检查这份{脚本/成片}，每条打“做到 / 部分做到 / 没做到 / 无法检查”，没做到写改法，无法检查写缺什么，不能把未观看的成片报为通过：
1. 有没有直给的、像真机拍的画面？是否平淡、日常、只有一处不对劲？
2. 有没有冷静的系统字段替画面下判决？
3. 鬼本体有没有出镜？（不能有）有没有突脸？（不能有）有没有一次“快要给了”？
4. 前 15 秒是否轻松、从聊天开始、交代清楚人物？有没有能暂停发现的线索？
5. 线索是否分两层：一遍就能发现的、回看才发现的？
6. 诡异是否只发生在一个空间？方位前后是否一致？是否单夜实时？
7. 每次切画面有没有由头？剧中人的反应是否合理？
8. 聊天里的他和画面里的他是否对得上？（应该对不上）
9. 有没有能截图、能做封面的标志画面？处境能不能转发给某个人？
10. 对白是不是人话？有没有设定式台词和赘述？
11. 结尾是否戛然而止、没有解释、没有普通夺舍？
12. 是否显著标注虚构与适用 AI 标识？有没有伪造新闻/官方/警方，或冒用真实人物机构造成误认？素材权利与制作署名是否如实？
13. 是否同一晚连续时间？回看是否只到今晚早些时候，无跨天或多年跳叙？
14. 每段是否都是主角手机可打开内容，主角只是看见者，无附身、复制或在监控/照片里出现？
15. 列出所有人声：主角是否零配音，配角正常短语音至多一两条且带线索，实拍无正常聊天，其余都是诡异本身？
16. 成片使用的首尾帧是否能追溯到已确认资产板，方位是否与方位图一致？脚本阶段未做资产则标“待第五步检查”。
最后列出“必须改”和“建议改”两组。
```

### P6　母版画面（图像生成）

通用规则：像真机记录，低清、噪点、构图不讲究、动作日常；不对劲的地方只有一处，藏在阴影里或画面边缘；**不让模型画任何文字**，时间戳、检测框、人数都由界面层叠加。逐条对照 `实拍质感.md` 第 4 节的九条要素来写：光线合时间、机位是装出来的、广角、曝光窄、颜色淡、码流画质、水印不让模型画、内容平淡且杂、镜头不动。

读取当前图像工具的实际规范；要求英文时把中文模板翻译后调用，画面中必要中文字按原文交给界面层。工具未开放时只交付提示词，不假称已出图。

```
一台{便宜的家用摄像头 / 吸顶半球监控 / 看护器……}在{几点}拍到的原始画面，像{谁}在手机上截的图；不是照片，不是电影。
机位：装在{哪里}，约{几}米高，{2.8mm 广角 / 鱼眼}，{多少度}俯拍{拍什么}；边缘直线明显外弯，四角暗角；构图是安装师傅定的，不为剧情构图。
光线：{此刻哪几盏灯亮着、哪些关了}；{灯 / 窗 / 屏幕 / 反光地面}过曝成白块，带光晕；暗部压黑、有噪点。（全部关灯时改成：摄像头自动切成黑白红外，灰、对比低、黑位发雾，近处被红外灯打白，四角暗，不要绿色夜视。）
内容：{场景，很日常}；{人物在哪、多大、在做什么，不看镜头，偏在一边，脸看不清}；杂物：{纸箱、线、拖把、灭火器、贴歪的通知……}。
{那一处不对劲（可以没有）：藏在阴影里或画面边缘，看不清全貌}。
画质：{几百万像素}的监控，但在手机 App 里看的是标清码流：细节被降噪抹平，暗部有一团团的亮度和彩色噪点，暗部和渐变有块状压缩，边缘锐化过度有细白边，饱和度低，{日光灯偏绿 / 暖灯偏黄}。
避免：电影光、HDR、均匀布光、光滑的 3D 渲染感、景深虚化、对称构图、主角正中、镜面一样干净的地面、任何文字、时间戳、标志、水印。横版 16:9。
```

生成后先跑 `scripts/cctv_look.py --report` 体检，再按对应设备预设后期（`实拍质感.md` 第 7 节）。候选数量与模型按授权及当前能力选，挑最平淡、最“不好看”的一张，不硬调未开放模型。

示例，教室看班母版（《已就寝》）：

```
学校教室监控的实时画面截图，摄像头装在教室前方侧面的墙上，机位偏低、偏侧，斜着拍到全班。高中教室晚自习，四十多个穿蓝白校服的学生低头写作业，桌上摞着课本和试卷，日光灯，黑板和窗帘都在画面里。最后一排靠窗有一个男生趴在桌上睡觉。
真实的教室监控画质：1080p 但压缩明显，暗部有噪点，轻微广角畸变，颜色偏淡。
平淡、普通、不像电影，画面里不要任何文字、时间戳、水印。横版 16:9。
```

示例，婴儿房夜视母版（《宝宝一直在笑》）：

```
婴儿看护摄像头的夜视画面截图，摄像头装在天花板角落，高角度俯拍整个婴儿房。画面中间是婴儿床，左边是关着的房门，右上角是一片空墙角。
黑白灰红外画质，低码率的块状压缩，暗部噪点，轻微鱼眼。墙角什么都看不到，不用绿色夜视。
安静、普通、不像电影，画面里不要任何文字和时间戳。横版 16:9。
```

上面两个例子的不对劲都来自“画面里的人”。主表达不是人的时候，母版照样这样写，只是那一处不对劲换成别的东西。

### P7　在母版上改出变体（图像编辑）

```
在这张图上修改，机位、构图、光线、其他所有人的位置和姿势都保持完全不变。
只改一处：{例如：最后一排靠窗的男生站了起来，脸朝后墙角站着，双手垂在身体两侧；他原来的座位空着}。
保持原图的监控画质、噪点和颜色。不要加任何文字。
```

编辑用的原图是**未后期的母版**；改完的变体和母版用同一个 `cctv_look.py` 预设、同一组参数做后期，切换时才不会跳。白天改成熄灯，要连同“彩色→红外”一起改，后期预设也从 `cctv_color` 换成 `cctv_ir`。

《已就寝》用过的变体：老师走到最后一排、手搭在他肩上；他脸朝墙站在后墙角；熄灯后的红外夜视版；全班坐得笔直、双手叠放、目视正前方。

主表达不是人时的变体思路：同一个机位，一夜里拍几张，每张多一点东西（灰上的脚印多一步、地图上多一个房间、门缝开大一点）；同一张照片的“放大局部”；同一个空房间，有一张东西被挪了位置；正常版和“少了什么”的版本（镜子里少一个人、影子少一个）。

通用细节：逼近镜头的人要“一直低着头，只露头顶和头发”；虚影要“半透明的人形剪影，像反光或动态模糊，看不清”。

### P8　图生视频（首帧 / 首尾帧）

```
用这张图作为第一帧{，第二张图作为最后一帧}。
镜头完全固定，不推、不摇、不变焦。
动作：{慢、幅度小，例如：老师从过道走到最后一排靠窗，把手搭在趴着的男生肩上}。
其他人保持原来的日常动作：{例如：其他学生继续低头写作业}。
没有任何东西朝镜头冲过来，没有突然的动作，不露出鬼脸。
保持第一帧的{监控 / 红外夜视 / 手机}画质：同样的噪点、同样的低清、同样的光线。
实拍里的人不正常聊天；只有确认脚本中的诡异人声动作可保留，如齐声背书的嘴部开合。
时长 {5–10} 秒。
```

只用第五步已确认资产对应的**未后期首帧/尾帧**，不改机位或人物位置。生成视频自带的声音不用，声音另行制作混音。生成后整段用 `cctv_look.py` 视频模式处理（与对应静帧同预设、`--fps 15 --stutter 0.02`），再按 24 fps 拆帧。模型若抹掉噪点或动作过顺，用后期恢复设备质感。

要全班张嘴背书时写清楚“每个人的嘴都在一张一合地念，头轻微地前后晃”，生成后逐帧放大前排的脸，确认嘴真的在动。生成后用 ffmpeg 按 24 fps 拆帧放进引擎。

### P9　必要的人声

先核对脚本：主角不配音，正常对白优先打字；配角至多一两条几秒、带线索的短语音，其余只做诡异本身的人声。调用前读当前 tts-prompter 和实际工具规范，不硬指定未开放音色或工具。

```
台词（一口气连续录完，句间自然停顿约 0.6 秒，后期再切开）：
{第 1 句}
{第 2 句}

人物：{确认脚本中的配角或诡异声源}
状态和口吻：{自然、随手录，不像念稿；只用原创或有授权声音}
音质：{例如：手机话筒，近距离，轻微底噪}
```

逐条试听并按当前可用转写工具核对文字；听不清或不自然时改口吻、重生成，关键声音出 3–5 版给用户挑，不把未确认人声直接放进正片。

耳语：
```
只有两个字“到了”。很轻的女声耳语，贴着麦克风，几乎是气声，紧跟在男声的“到了”后面，像回声但不是回声。
```

哼唱：
```
一个普通女人深夜闭着嘴轻轻哼摇篮曲（曲调：小星星），嗓音普通，没有颤音，没有混响，不张嘴唱，像隔着一面墙。
```

### P10　伪背书（一屋子人在背，却一个字都听不懂）

把课文的字句打乱、倒装、单字随便换位，读起来有古文的节奏，但不成句。同一段文字用 8–10 个不同的音色各录一遍，再交给 `scripts/crowd_recite.py` 叠成一个班。

```
台词（照字念，不要纠正，不要停顿太久）：
兰予清曲之清而野兰，水冰寒惟之于而水矣。学博子君日三徐其省，明知岂忽焉已。高望登远，学所之如步者，忽风顺而疾加飞升也……
人物：高一学生，晚自习上齐声背书
状态和口吻：一板一眼、匀速、不带感情，像背过一百遍
音质：干声，近距离，不加混响（混响和电话音质后期统一加）
```

不要用音效模型直接生成“一群人背书”，转写出来全是不相干的对白；真课文齐背又会被听出是哪一篇。

### P11　环境音和音效

```
{例：深夜空教室的底噪：日光灯镇流器的电流声，很远的走廊偶尔有回声，没有人声，没有音乐，30 秒，可以循环}
{例：老式学校电铃，金属铃锤快速敲击，刺耳，持续 6 秒，教室里有一点回声}
{例：门外楼道里两个人的脚步声，由远及近，在门口停下，一个步子重，一个很轻，没有说话声}
```

只做剧中真实存在的声源；不做配乐，不做惊吓音效。手机界面音（按键、收消息、点按、锁屏；发送消息不加发送音）不要用音效模型生成，也不要自己重新合成，一律用 `scripts/ui_sounds.py` 里的随附库基准；回铃音、挂断音、来电铃这类按 `真实感.md` 第 8 节用脚本合成。
