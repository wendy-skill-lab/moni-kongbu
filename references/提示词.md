## 定方向

### P1　出 3–4 个方向（最恐怖的点 + 场景）

```
你是一个原创竖屏“模拟恐怖”短片账号的编剧。这个账号的差异化是：每一期都有一段“直给”的、像真机留下来的记录（监控、照片、录像、录音、门锁记录、地图都可以，不限于摄像头），由冷静的系统字段说出不对劲，从不突脸。

底层原则（不规定画面长什么样）：
1. 恐怖的源头不给全貌：只给它留下的痕迹、读数、温度、轨迹、声音、动物的反应，或者一个被借走的熟人；不出现看得清五官和全身的鬼。
2. 观众要亲眼看到或亲耳听到一份证据，来自一段非聊天的真实记录。
3. 揭示靠“动起来”（云台转动、捏合放大、回放逐帧、相册上翻、长按实况照片）或者“对照”（平时 98%，今晚 63%）。
4. 两个信息对不上：人说的话和记录里的事实对不上。
5. 结尾戛然而止，或者把时间往前推，不写“我也被附身了”。
6. 诡异只发生在一个空间里，其他空间只作辅助；单夜实时，不跨天。

{可选：用户给的场景或灵感}
自己的已做或已提方向（避免重复）：{粘贴当前项目 选题记录.md 里的片名}

请给出 {3/4} 个方向。每个方向写：
- 片名（2–5 字，像一句话或一个系统字段）和类别（A 聊天主线穿插设备 / B 开头就给吓人的东西 / C 只有一个监测器界面）
- 最恐怖的点：一个画面或一个声音，写清观众具体看到、听到什么，在空间的哪里，系统字段的原文

- 场景：主空间、辅助空间、时间（几点到几点）
- 现实处境：观众为什么代入，会转发给谁
- 一句话钩子

## 写脚本

### P2　视觉呈现脚本

```
请把选定的方向写成“视觉呈现脚本”。这份脚本是给制作用的，重点是每一段画面怎么呈现。

格式：
# 《{片名}》视觉呈现脚本
竖屏 9:16，全程是 {主角} 的 iPhone 屏幕录制，片头 3.5 秒观看提示，时间按含提示的版本计算。
## 人物（表格：角色 / 微信备注 / 头像画面内容 / 一句话说明）
## 场景与方位（主空间的机位、门、窗、墙角、主角的位置；辅助空间；时间）
## 用到的界面（具体到 App 和页面）
## 分段
每段写：段号、时间段、标题；“画面：”写屏幕上是什么、怎么动、点了什么；对白用“> 角色：内容”；直给画面标【实拍 ①】，写清机位、质感、谁在哪、系统字段原文、那一处不对劲；“声音：”写这一段能听到什么。
## 结尾（最后一个画面、最后一个声音、黑屏后有什么）
## 素材清单（静帧、视频、语音、音效，各自用在哪一段）

结构：前 15 秒轻松，从微信聊天开始，最好带一张图片或一条语音，图片里可以藏一个隐喻；然后第一次直给画面；之后聊天和画面交替推进，每 20–30 秒升级一次；矛盾点是“我”发现不对劲后质问，诡异随之发生；最后戛然而止。

要求：
1. 每次切画面都要有由头（推送来了才点开、问完人才自己去看）。
2. 方位前后一致，机位不动。
3. 数字随剧情推进（时钟、电量、人数、计时）。
4. 对白像真人聊天：短句、语气词、一句话拆成几条发、不交代彼此早就知道的事。
5. 剧中人的反应合乎常理；一段说清楚了就往下走，不写来回解释。
6. 恐怖的源头不能被看清，只能从它留下的东西里感觉到：系统字段、痕迹、读数、阴影、声音、动物的反应。按方向卡片上定的主表达来写，不要自动换回“熟人站在墙角”。
```

### P3　对白改成人话

```
下面是一段手机聊天对白，请改得更像真人在微信上打字：
{粘贴对白}

规则：
- 删掉所有“交代设定”的句子，人不会告诉对方双方都知道的事。
- 长句拆成 2–3 条连发；句尾少用句号，可以用空格断句；可以有“？”“。。。”“啊”“哈”“我去”。
- 先回情绪，再回内容；可以只回一个“？”。
- 称呼按关系来：夫妻叫“老公”“老周”，同事叫“小许”，家长群里叫“陈默妈妈”，代驾叫“师傅”。
- 要发图的地方写成“（发一张{图片内容}）”。
保留原来的剧情信息点，不加新剧情。输出改写后的对白，每处改动后用括号写一句原因。

示例：
原句：“我是今晚值夜班的护士，我们科室最近发生了怪事。”
改后：“小许，你是不是忘了什么（发一张工牌照片）”“我去！工牌忘拿了”
```

### P4　脚本自检、审片自检

```
请按下面 12 条检查这份{脚本/成片}，每条打“做到 / 部分做到 / 没做到”，没做到的写具体改法：
1. 有没有直给的、像真机拍的画面？是否平淡、日常、只有一处不对劲？
2. 有没有冷静的系统字段替画面下判决？
3. 鬼本体有没有出镜？（不能有）有没有突脸？（不能有）有没有一次“快要给了”？
4. 前 15 秒是否轻松、从聊天开始、交代清楚人物？有没有能暂停发现的线索？
5. 线索是否分两层：一遍就能发现的、回看才发现的？
6. 诡异是否只发生在一个空间？方位前后是否一致？是否单夜实时？
7. 每次切画面有没有由头？剧中人的反应是否合理？
8. 聊天里的他和画面里的他是否对得上？（应该对不上）
9. 有没有能截图、能做封面的标志画面？处境能不能转发给某个人？
10. 对白是不是人话？有没有设定式台词和赘述？
11. 结尾是否戛然而止、没有解释、没有普通夺舍？
12. 是否标注虚构？有没有伪造新闻、官方、警方或真实品牌？
最后列出“必须改”和“建议改”两组。
```

### P6　母版画面（图像生成）

通用规则：像真机记录，低清、噪点、构图不讲究、动作日常；不对劲的地方只有一处，藏在阴影里或画面边缘；**不让模型画任何文字**，时间戳、检测框、人数都由界面层叠加。逐条对照 `实拍质感.md` 第 4 节的九条要素来写：光线合时间、机位是装出来的、广角、曝光窄、颜色淡、码流画质、水印不让模型画、内容平淡且杂、镜头不动。

generate_image 要求英文提示词：下面的中文模板写好后翻成英文再调用，画面里要出现的中文字照原样保留。

```
一台{便宜的家用摄像头 / 吸顶半球监控 / 看护器……}在{几点}拍到的原始画面，像{谁}在手机上截的图；不是照片，不是电影。
机位：装在{哪里}，约{几}米高，{2.8mm 广角 / 鱼眼}，{多少度}俯拍{拍什么}；边缘直线明显外弯，四角暗角；构图是安装师傅定的，不为剧情构图。
光线：{此刻哪几盏灯亮着、哪些关了}；{灯 / 窗 / 屏幕 / 反光地面}过曝成白块，带光晕；暗部压黑、有噪点。（全部关灯时改成：摄像头自动切成黑白红外，灰、对比低、黑位发雾，近处被红外灯打白，四角暗，不要绿色夜视。）
内容：{场景，很日常}；{人物在哪、多大、在做什么，不看镜头，偏在一边，脸看不清}；杂物：{纸箱、线、拖把、灭火器、贴歪的通知……}。
{那一处不对劲（可以没有）：藏在阴影里或画面边缘，看不清全貌}。
画质：{几百万像素}的监控，但在手机 App 里看的是标清码流：细节被降噪抹平，暗部有一团团的亮度和彩色噪点，暗部和渐变有块状压缩，边缘锐化过度有细白边，饱和度低，{日光灯偏绿 / 暖灯偏黄}。
避免：电影光、HDR、均匀布光、光滑的 3D 渲染感、景深虚化、对称构图、主角正中、镜面一样干净的地面、任何文字、时间戳、标志、水印。横版 16:9。
```

生成后先跑 `scripts/cctv_look.py --report` 体检，再按对应设备的预设做后期（`实拍质感.md` 第 7 节）。两个模型各出几张，挑最平淡、最“不好看”的一张。

示例，教室看班母版（《已就寝》）：

```
学校教室监控的实时画面截图，摄像头装在教室前方侧面的墙上，机位偏低、偏侧，斜着拍到全班。高中教室晚自习，四十多个穿蓝白校服的学生低头写作业，桌上摞着课本和试卷，日光灯，黑板和窗帘都在画面里。最后一排靠窗有一个男生趴在桌上睡觉。
真实的教室监控画质：1080p 但压缩明显，暗部有噪点，轻微广角畸变，颜色偏淡。
平淡、普通、不像电影，画面里不要任何文字、时间戳、水印。横版 16:9。
```

示例，婴儿房夜视母版（《宝宝一直在笑》）：

```
婴儿看护摄像头的夜视画面截图，摄像头装在天花板角落，高角度俯拍整个婴儿房。画面中间是婴儿床，左边是关着的房门，右上角是一片空墙角。
灰绿色红外画质，低码率的块状压缩，暗部噪点，轻微鱼眼。墙角什么都看不到。
安静、普通、不像电影，画面里不要任何文字和时间戳。横版 16:9。
```

上面两个例子的不对劲都来自“画面里的人”。主表达不是人的时候，母版照样这样写，只是那一处不对劲换成别的东西。

### P7　在母版上改出变体（图像编辑）

```
在这张图上修改，机位、构图、光线、其他所有人的位置和姿势都保持完全不变。
只改一处：{例如：最后一排靠窗的男生站了起来，脸朝后墙角站着，双手垂在身体两侧；他原来的座位空着}。
保持原图的监控画质、噪点和颜色。不要加任何文字。
```

编辑用的原图是**未后期的母版**；改完的变体和母版用同一个 `cctv_look.py` 预设、同一组参数做后期，切换时才不会跳。白天改成熄灯，要连同“彩色→红外”一起改，后期预设也从 `cctv_color` 换成 `cctv_ir`。

《已就寝》用过的变体：老师走到最后一排、手搭在他肩上；他脸朝墙站在后墙角；熄灯后的红外夜视版；全班坐得笔直、双手叠放、目视正前方。

主表达不是人时的变体思路：同一个机位，一夜里拍几张，每张多一点东西（灰上的脚印多一步、地图上多一个房间、门缝开大一点）；同一张照片的“放大局部”；同一个空房间，有一张东西被挪了位置；正常版和“少了什么”的版本（镜子里少一个人、影子少一个）。

通用细节：逼近镜头的人要“一直低着头，只露头顶和头发”；虚影要“半透明的人形剪影，像反光或动态模糊，看不清”。

### P8　图生视频（首帧 / 首尾帧）

```
用这张图作为第一帧{，第二张图作为最后一帧}。
镜头完全固定，不推、不摇、不变焦。
动作：{慢、幅度小，例如：老师从过道走到最后一排靠窗，把手搭在趴着的男生肩上}。
其他人保持原来的日常动作：{例如：其他学生继续低头写作业}。
没有任何东西朝镜头冲过来，没有突然的动作，不露出鬼脸。
保持第一帧的{监控 / 红外夜视 / 手机}画质：同样的噪点、同样的低清、同样的光线。
时长 {5–10} 秒。
```

首帧用**未后期的母版**。生成后整段用 `cctv_look.py` 视频模式处理（与母版同一预设、`--fps 15 --stutter 0.02`），再按 24 fps 拆帧。视频模型常把噪点抹掉、动作做得很顺，后期要把这两样补回来。

要全班张嘴背书时写清楚“每个人的嘴都在一张一合地念，头轻微地前后晃”，生成后逐帧放大前排的脸，确认嘴真的在动。生成后用 ffmpeg 按 24 fps 拆帧放进引擎。

### P9　语音

```
台词（一口气连续录完，句间自然停顿约 0.6 秒，后期再切开）：
{第 1 句}
{第 2 句}

人物：{例如：十六岁的高中男生，压着嗓子在宿舍里小声说话}
状态和口吻：{例如：有点不耐烦，含糊，带“啊”“嗯”，像真的在打电话，不像念稿}
音质：{例如：手机话筒，近距离，轻微底噪}
```

技巧：让说话人先重复一遍对方的问题（“绕路？没有啊……没绕。”）。每条都用 `manus-speech-to-text` 转写逐字核对，听不清的重新生成。语音不自然时，一次生成 3–5 个音色或口吻给用户挑。

耳语：
```
只有两个字“到了”。很轻的女声耳语，贴着麦克风，几乎是气声，紧跟在男声的“到了”后面，像回声但不是回声。
```

哼唱：
```
一个普通女人深夜闭着嘴轻轻哼摇篮曲（曲调：小星星），嗓音普通，没有颤音，没有混响，不张嘴唱，像隔着一面墙。
```

### P10　伪背书（一屋子人在背，却一个字都听不懂）

把课文的字句打乱、倒装、单字随便换位，读起来有古文的节奏，但不成句。同一段文字用 8–10 个不同的音色各录一遍，再交给 `scripts/crowd_recite.py` 叠成一个班。

```
台词（照字念，不要纠正，不要停顿太久）：
兰予清曲之清而野兰，水冰寒惟之于而水矣。学博子君日三徐其省，明知岂忽焉已。高望登远，学所之如步者，忽风顺而疾加飞升也……
人物：高一学生，晚自习上齐声背书
状态和口吻：一板一眼、匀速、不带感情，像背过一百遍
音质：干声，近距离，不加混响（混响和电话音质后期统一加）
```

不要用音效模型直接生成“一群人背书”，转写出来全是不相干的对白；真课文齐背又会被听出是哪一篇。

### P11　环境音和音效

```
{例：深夜空教室的底噪：日光灯镇流器的电流声，很远的走廊偶尔有回声，没有人声，没有音乐，30 秒，可以循环}
{例：老式学校电铃，金属铃锤快速敲击，刺耳，持续 6 秒，教室里有一点回声}
